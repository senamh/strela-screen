# Third-party software

Strela Screen bundles the following libraries, without modifications to their source:

- **Mediabunny 1.56.1** — Mozilla Public License 2.0. Media demuxing, decoding, encoding and MP4/WebM muxing. Source: https://github.com/Vanilagy/mediabunny/tree/v1.56.1 and the exact npm source package https://registry.npmjs.org/mediabunny/-/mediabunny-1.56.1.tgz . The original source is included in that package's src directory. License included in the built extension under licenses/mediabunny.txt. MPL-covered files remain available under MPL 2.0.
- **fflate 0.8.3** — MIT License, copyright 2026 Arjun Barrett. Portable .strela ZIP archives. Source: https://github.com/101arrowz/fflate and exact package https://registry.npmjs.org/fflate/-/fflate-0.8.3.tgz . License included under licenses/fflate.txt.
- **esbuild 0.28.2** — MIT License. Development/build dependency; executable is not distributed in the extension.
- **gifenc 1.0.3** — MIT License. GIF palette reduction and encoding. Source: https://github.com/mattdesl/gifenc and exact package https://registry.npmjs.org/gifenc/-/gifenc-1.0.3.tgz . License is included under licenses/gifenc.txt.

OpenScreen, Flowtake, Recordly and Reframed were discussed as research candidates. No code or assets from those applications are part of this build. Strela's original fixture artwork and interface were created for this project.
