# Strela Screen 0.2.0 — браузерная бета

## Установка

1. Распакуйте ZIP.
2. В Chrome откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика» → «Загрузить распакованное расширение».
4. Выберите вложенную папку **strela-screen**, в которой находится `manifest.json`.
5. На нужной странице нажмите значок Strela → **Open studio**.

## Использование

- **Record**: запись экрана, окна приложения или вкладки. Фактический источник выбирается в диалоге браузера.
- **Browser tab**: запись исходной вкладки расширением с точками кликов для автоматического приближения. После перехода на другую страницу сбор кликов может прекратиться.
- **Pause / Resume / Stop**: управление записью в студии.
- **Split / Remove clip / Apply trim**: монтаж без изменения оригинала.
- На паузе нажмите нужное место в предпросмотре, чтобы поставить точку приближения. Точку можно удалить в строке Focus.
- **Canvas**: горизонтальный, вертикальный или квадратный ролик. Вертикальный формат обрезает широкий источник; задайте фокус на нужном содержимом.
- **Export video**: MP4, WebM или GIF; после обработки нажмите **Download video**. Звук в GIF не поддерживается.
- **Save project**: резервная копия `.strela`, включающая исходное видео. Открывается через **Import**.
- **Original**: скачать исходную запись без оформления.

Для проверки без записи собственного экрана откройте **Try demo** в пустой студии.

## Важно

Это бета, а не готовый полноценный аналог Screen Studio. Браузерная студия проверялась в Chrome на macOS; установку расширения и Windows/Edge ещё нужно проверить отдельно. Системный звук зависит от источника и ОС. Автоматическое отслеживание мыши в любых приложениях и перерисовка плавного курсора требуют отдельной нативной программы, которой в этой сборке нет.

Проекты хранятся локально в профиле браузера. Удаление расширения или очистка данных могут удалить библиотеку — сохраняйте `.strela`-копии. Во время экспорта можно перейти в другую вкладку, но студию закрывать нельзя. Длинные записи и 4K требуют много памяти.
